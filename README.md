# Chatbot

This repository focuses on learning and understanding how chatbots work, starting from the fundamentals and gradually exploring more advanced implementations across different programming languages and comparing each implementation.

## 🎯 Project Goal

The goal of this project is to understand the foundations of chatbot development by building one from scratch and improving it step by step.

By implementing the same concepts in different programming languages, I aim to understand the underlying logic, compare their implementations, and explore factors such as time complexity, space complexity, execution time, and memory usage.

This repository is also intended to serve as a learning resource for others who want to understand chatbot development from the ground up, strengthen their fundamentals, and gradually progress towards building more advanced chatbots independently.

## 📊 Performance & Complexity Analysis

As the project develops, implementations will be analyzed and compared based on:

- **Time complexity:** How processing requirements change as the chatbot grows.
- **Space complexity:** How memory requirements vary with different implementations.
- **Execution time:** How long the chatbot takes to process inputs.
- **Memory usage:** The memory consumed during execution.
- **Language comparison:** Differences in implementation and runtime performance.

Comparisons will use documented test cases and measurement methods wherever practical.
